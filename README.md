# 📚 Online Bookstore Management System

A simple PostgreSQL database project developed for BCA students to manage books, customers, and orders in an online bookstore.

---

# 🛠️ Technologies Used
- PostgreSQL
- SQL
- pgAdmin

---

# 📂 Database Tables

## 1. Books
Stores book details like:
- Title
- Author
- Genre
- Price
- Stock

## 2. Customers
Stores customer information like:
- Name
- Email
- City
- Country

## 3. Orders
Stores order details:
- Customer Orders
- Quantity
- Total Amount
- Order Date
